## About
- **What it is:** An unchanged copy of E2B, an open-source project that gives AI agents their own cloud computers to run code in.
- **Business:** learning
- **Status:** inactive since 2023-09
- **Source:** agent research 2026-11-04

## Getting Started & Documentation

Visit [docs](https://e2b.dev/docs) to get started with the SDK.

### Python
```bash
pip install e2b
```

### JavaScript & TypeScript
```bash
npm install @e2b/sdk
```
